# Состояние проекта / Project status

Подготовка, [анализ MVP](analysis/mvp.md), [архитектура](architecture/system.md) и API с PostgreSQL реализованы. На отдельной базе PostgreSQL выполнено 9 проверок pytest, включая повтор под конкуренцией, двойное списание, откат, неизменяемость проводок и контроль доступа. [OpenAPI](api/openapi.json) экспортирован из FastAPI.

Следующий шаг — клиентские и операционные экраны, затем лаборатория на отдельной базе и проверка полного запуска Compose.
