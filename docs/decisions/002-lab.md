# ADR-002 · Isolated reliability lab

Status: accepted.

Require an explicit separate PostgreSQL database, enabled only in the local demo profile. The outer admin-only endpoint accepts a scenario enum. For each run, create fresh synthetic fixtures and call the real FastAPI routes through an in-process ASGI HTTP transport against that database. The rollback hook is injected privately into the lab application instance. No ordinary request parameter can enable it. Snapshot the ledger on both sides of the requests.
